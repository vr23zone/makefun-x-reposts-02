This entry takes part in make.fun's X reposts bounty: from one public X account we answer make.fun's newest posts with quote posts and direct replies, and `POSTS.json` names those posts. The house then reads each named post's public counts and scores the entry on the reposts, quotes and likes the posts collect. The small program in `main.ts` simply validates `POSTS.json` and copies it into the harness output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
